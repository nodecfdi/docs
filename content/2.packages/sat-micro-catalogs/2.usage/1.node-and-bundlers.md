El paquete distribuye módulos ESM puros con declaraciones de tipos `.d.ts`. Puedes elegir entre tres niveles de granularidad según lo que necesite tu proyecto.

## Niveles de importación

### 1. Por dominio (recomendado)

Agrupa todos los catálogos de una versión o complemento específico en un solo import limpio. Es ideal para aplicaciones con Vite, Nuxt, Next.js, Astro o Node.js:

```ts [app/pdf/cfdi-labels.ts]
import {
  cfdi40FormasPago,
  cfdi40MetodosPago,
  cfdi40Monedas,
  cfdi40RegimenesFiscales,
  cfdi40UsosCfdi,
} from '@nodecfdi/sat-micro-catalogs/cfdi-40';
```

### 2. Por catálogo individual

Si quieres importar únicamente un archivo sin cargar el resto del dominio (útil en funciones serverless o micro-bundles):

```ts [app/utils/currency.ts]
import { cfdi40Monedas } from '@nodecfdi/sat-micro-catalogs/catalogs/cfdi_40_monedas';

export function formatCurrency(code: string): string {
  return cfdi40Monedas.label(code);
}
```

### 3. Entrypoint raíz

Reexporta todos los catálogos y helpers desde un único punto de entrada. Los bundlers modernos aplicarán *tree-shaking* automáticamente, aunque en Node.js sin bundler conviene preferir imports por dominio o por catálogo para cargar menos archivos en memoria.

```ts [app/catalogs.ts]
import { cfdi40UsosCfdi, nominaBancos } from '@nodecfdi/sat-micro-catalogs';
```

## Uso típico en generación de PDFs

Los métodos `.label()` y `.text()` están pensados para representaciones impresas de CFDI: si la clave no existe en el catálogo, devuelven la propia clave (o un *fallback* personalizado) en lugar de lanzar excepciones o imprimir `undefined`.

```ts [app/pdf/render-header.ts]
import {
  cfdi40FormasPago,
  cfdi40MetodosPago,
  cfdi40RegimenesFiscales,
  cfdi40TiposComprobantes,
  cfdi40UsosCfdi,
} from '@nodecfdi/sat-micro-catalogs/cfdi-40';

interface CfdiResumen {
  tipoDeComprobante: string;
  metodoPago: string;
  formaPago: string;
  regimenFiscalEmisor: string;
  usoCfdiReceptor: string;
}

export function buildPdfLabels(cfdi: CfdiResumen) {
  return {
    tipo: cfdi40TiposComprobantes.label(cfdi.tipoDeComprobante),
    metodoPago: cfdi40MetodosPago.label(cfdi.metodoPago),
    formaPago: cfdi40FormasPago.label(cfdi.formaPago),
    regimenEmisor: cfdi40RegimenesFiscales.label(cfdi.regimenFiscalEmisor),
    usoCfdi: cfdi40UsosCfdi.label(cfdi.usoCfdiReceptor),
    // Separador y fallback personalizados
    usoTexto: cfdi40UsosCfdi.text(cfdi.usoCfdiReceptor, 'No especificado'),
  };
}
```

::tip
La primera llamada a `.get()`, `.has()`, `.text()` o `.label()` construye un `Map` interno en memoria; todas las consultas posteriores sobre ese catálogo se resuelven en `O(1)`.
::
