Casi todos los catálogos del SAT incluyen columnas `vigencia_desde` y `vigencia_hasta` en formato ISO (`YYYY-MM-DD`). `SatCatalog` usa estas fechas para ayudarte a mostrar únicamente claves válidas en formularios sin perder soporte para comprobantes históricos.

## Generar opciones para `<select>`

El método `.options()` devuelve un arreglo de objetos `{ value, text, label, item }` listo para renderizar en Vue, React, Svelte o HTML nativo:

```ts [app/forms/uso-cfdi-options.ts]
import { cfdi40UsosCfdi } from '@nodecfdi/sat-micro-catalogs/cfdi-40';

const options = cfdi40UsosCfdi.options({
  activeOn: new Date(),
});

// [
//   {
//     value: 'G01',
//     text: 'Adquisición de mercancías.',
//     label: 'G01 - Adquisición de mercancías.',
//     item: { id: 'G01', texto: 'Adquisición de mercancías.', ... }
//   },
//   ...
// ]
```

## Combinar vigencia con reglas fiscales

Puedes pasar un `filter` tipado junto con `activeOn` y un `separator` personalizado. Por ejemplo, para mostrar solo usos de CFDI vigentes aplicables a **personas físicas** o **personas morales**:

```ts [app/forms/uso-cfdi-by-person.ts]
import { cfdi40UsosCfdi } from '@nodecfdi/sat-micro-catalogs/cfdi-40';

export function getUsoCfdiOptions(tipoPersona: 'fisica' | 'moral', fecha: Date = new Date()) {
  return cfdi40UsosCfdi.options({
    activeOn: fecha,
    separator: ' — ',
    filter: (item) => (tipoPersona === 'fisica' ? item.aplica_fisica : item.aplica_moral) === 1,
  });
}
```

## Obtener registros vigentes sin transformar

Si necesitas los objetos originales del catálogo filtrados por fecha, usa `.active()`:

```ts [app/forms/regimenes.ts]
import { cfdi40RegimenesFiscales } from '@nodecfdi/sat-micro-catalogs/cfdi-40';

// Acepta un objeto Date o una cadena ISO 'YYYY-MM-DD'
const vigentesHoy = cfdi40RegimenesFiscales.active();
const vigentesEn2023 = cfdi40RegimenesFiscales.active('2023-06-15');
```

::tip
**Formularios vs PDFs históricos**: usa `activeOn: new Date()` al poblar `<select>` para evitar que el usuario elija claves dadas de baja por el SAT. En cambio, al imprimir PDFs de facturas emitidas en años anteriores, usa `.label(clave)` o `.text(clave)` directamente sobre el catálogo completo para resolver incluso claves ya vencidas.
::
