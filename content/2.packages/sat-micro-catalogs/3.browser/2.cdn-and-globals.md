Todos los bundles IIFE se publican dentro del paquete npm en `dist/iife/`, por lo que están disponibles automáticamente en los principales CDNs y también pueden servirse de forma local.

## Cargar desde un CDN

::code-group
```html [unpkg]
<script src="https://unpkg.com/@nodecfdi/sat-micro-catalogs@2/dist/iife/cfdi-40.iife.js"></script>
```

```html [jsDelivr]
<script src="https://cdn.jsdelivr.net/npm/@nodecfdi/sat-micro-catalogs@2/dist/iife/cfdi-40.iife.js"></script>
```
::

::warning
En producción fija siempre al menos la versión mayor (`@2`) o una versión exacta (`@2.0.0`) en la URL del CDN para evitar cambios inesperados al publicarse futuras versiones.
::

## Combinar múltiples dominios en una misma página

Como cada dominio usa su propio nombre global (`ncCatalogCfdi40`, `ncCatalogNomina`, `ncCatalogCcp31`, etc.), puedes incluir varios `<script>` en la misma página sin que se sobrescriban entre sí:

```html [nomina.html]
<script src="https://cdn.jsdelivr.net/npm/@nodecfdi/sat-micro-catalogs@2/dist/iife/cfdi-40.iife.js"></script>
<script src="https://cdn.jsdelivr.net/npm/@nodecfdi/sat-micro-catalogs@2/dist/iife/nomina.iife.js"></script>
<script>
  const { cfdi40Monedas } = window.ncCatalogCfdi40;
  const { nominaBancos, nominaTiposDeducciones } = window.ncCatalogNomina;

  console.log(cfdi40Monedas.text('MXN'));          // "Peso Mexicano"
  console.log(nominaBancos.label('002'));          // "002 - BANAMEX"
  console.log(nominaTiposDeducciones.text('001')); // "Seguridad social"
</script>
```

## Servir los bundles desde tu propio servidor

Si instalaste el paquete con npm/pnpm y prefieres servir los archivos estáticos desde tu backend sin depender de un CDN externo, el paquete exporta el subpath `./iife/*`:

```ts [scripts/copy-assets.ts]
import { copyFile } from 'node:fs/promises';
import { createRequire } from 'node:module';

const require = createRequire(import.meta.url);
const cfdi40BundlePath = require.resolve('@nodecfdi/sat-micro-catalogs/iife/cfdi-40');

await copyFile(cfdi40BundlePath, 'public/js/cfdi-40.iife.js');
```

## Contenido expuesto por cada global

Cada variable global (`ncCatalogCfdi40`, `ncCatalogNomina`, etc.) expone:

- Todos los catálogos del dominio como instancias de `SatCatalog` (o arreglo `readonly` en el caso de reglas de tasa o cuota).
- Los arreglos crudos `<nombre>Data` de cada catálogo.
- Los helpers `SatCatalog` y `createCatalog` por si necesitas crear catálogos propios en el cliente.
