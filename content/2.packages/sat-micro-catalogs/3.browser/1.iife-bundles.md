Para aplicaciones que no usan un bundler de JavaScript —o donde prefieres cargar los catálogos mediante una etiqueta `<script>`— el paquete incluye **bundles IIFE minificados** (target `ES2020`) separados por dominio en `dist/iife/`.

Cada bundle expone una variable global corta con el prefijo `ncCatalog` para evitar colisiones.

## Bundles disponibles

| Archivo | Variable global (`window.*`) | Minificado | Gzip |
| --- | --- | ---: | ---: |
| `dist/iife/cfdi-40.iife.js` | `ncCatalogCfdi40` | 95.43 KB | **11.97 KB** |
| `dist/iife/nomina.iife.js` | `ncCatalogNomina` | 50.01 KB | **8.54 KB** |
| `dist/iife/ccp-31.iife.js` | `ncCatalogCcp31` | 94.37 KB | **13.39 KB** |
| `dist/iife/ret-20.iife.js` | `ncCatalogRet20` | 35.24 KB | **6.19 KB** |
| `dist/iife/cce-20.iife.js` | `ncCatalogCce20` | 14.42 KB | **2.95 KB** |
| `dist/iife/hyp-10.iife.js` | `ncCatalogHyp10` | 6.37 KB | **1.82 KB** |
| `dist/iife/pagos.iife.js` | `ncCatalogPagos` | 2.53 KB | **1.08 KB** |
| `dist/iife/all.iife.js` | `ncCatalog` | 549.24 KB | **71.32 KB** |

::tip
En la mayoría de las aplicaciones de facturación solo necesitas `cfdi-40.iife.js` (~12 KB gzip). Evita cargar `all.iife.js` en producción a menos que realmente utilices todos los complementos y versiones anteriores.
::

## Ejemplo completo en HTML

Este ejemplo carga únicamente el dominio de CFDI 4.0, llena un `<select>` con los usos de CFDI vigentes y muestra la etiqueta resuelta al cambiar la selección:

```html [index.html]
<!doctype html>
<html lang="es">
  <head>
    <meta charset="utf-8" />
    <title>Catálogos SAT en navegador</title>
  </head>
  <body>
    <label for="uso-cfdi">Uso de CFDI:</label>
    <select id="uso-cfdi"></select>
    <p id="resultado"></p>

    <script src="https://unpkg.com/@nodecfdi/sat-micro-catalogs/dist/iife/cfdi-40.iife.js"></script>
    <script>
      const { cfdi40UsosCfdi } = window.ncCatalogCfdi40;
      const select = document.getElementById('uso-cfdi');
      const resultado = document.getElementById('resultado');

      for (const option of cfdi40UsosCfdi.options({ activeOn: new Date() })) {
        const el = document.createElement('option');
        el.value = option.value;
        el.textContent = option.label;
        select.appendChild(el);
      }

      select.addEventListener('change', () => {
        resultado.textContent = cfdi40UsosCfdi.text(select.value);
      });
    </script>
  </body>
</html>
```
