Todos los catálogos clave-valor generados por `@nodecfdi/sat-micro-catalogs` son instancias de `SatCatalog<T>`. También puedes importar la clase y su fábrica directamente desde `@nodecfdi/sat-micro-catalogs/helpers` o desde cualquier dominio.

## `createCatalog(items, config?)`

Crea una instancia de `SatCatalog<T>` a partir de un arreglo de solo lectura.

```ts [app/custom-catalog.ts]
import { createCatalog } from '@nodecfdi/sat-micro-catalogs/helpers';

const estatus = createCatalog([
  { id: 'A', texto: 'Activo', vigencia_desde: '2024-01-01', vigencia_hasta: '' },
  { id: 'B', texto: 'Baja', vigencia_desde: '2024-01-01', vigencia_hasta: '' },
]);

estatus.label('A'); // "A - Activo"
```

Si tus objetos usan nombres de columna distintos a `id` y `texto`, pásalos en `config`:

```ts [app/custom-fields.ts]
import { createCatalog } from '@nodecfdi/sat-micro-catalogs/helpers';

const permisos = createCatalog(
  [{ clave: 'P01', descripcion: 'Permiso general' }],
  { keyField: 'clave', textField: 'descripcion' },
);

permisos.label('P01'); // "P01 - Permiso general"
```

## Propiedades y métodos de `SatCatalog<T>`

| Miembro | Firma | Descripción |
| --- | --- | --- |
| `items` | `readonly T[]` | Arreglo original de registros en modo solo lectura. |
| `size` | `number` | Número total de elementos del catálogo. |
| `all()` | `() => readonly T[]` | Devuelve todos los elementos del catálogo. |
| `has(key)` | `(key: string) => boolean` | Verifica en `O(1)` si existe la clave. |
| `get(key)` | `(key: string) => T \| undefined` | Devuelve el objeto completo tipado en `O(1)`, o `undefined`. |
| `text(key, fallback?)` | `(key: string, fallback?: string) => string` | Devuelve el texto descriptivo del registro o `fallback` (por defecto `key`). |
| `label(key, separator?, fallback?)` | `(key: string, separator?: string, fallback?: string) => string` | Devuelve `${clave}${separator}${texto}` (separador por defecto `' - '`). Si `keyField === textField`, devuelve solo la clave. |
| `filter(predicate)` | `(predicate: (item: T) => boolean) => T[]` | Filtra los elementos con un predicado tipado. |
| `active(date?)` | `(date?: Date \| string) => T[]` | Devuelve los elementos vigentes en la fecha indicada (por defecto `new Date()`), evaluando `vigencia_desde` y `vigencia_hasta` en formato `YYYY-MM-DD`. |
| `options(config?)` | `(config?: SatCatalogOptionsConfig<T>) => SatCatalogOption<T>[]` | Genera objetos `{ value, text, label, item }` listos para `<select>`, con filtros opcionales de vigencia, separador y predicado. |
| `[Symbol.iterator]()` | `() => IterableIterator<T>` | Permite iterar directamente con `for (const item of catalog)` o `[...catalog]`. |

## Tipos públicos

Exportados desde `@nodecfdi/sat-micro-catalogs/types` (y reexportados en la raíz y en cada dominio):

```ts
export type SatCatalogRecord = Record<string, string | number | boolean | null>;

export interface SatCatalogConfig<
  T extends SatCatalogRecord,
  K extends keyof T = keyof T,
  L extends keyof T = keyof T,
> {
  keyField?: K;
  textField?: L;
}

export interface SatCatalogOption<T extends SatCatalogRecord = SatCatalogRecord> {
  value: string;
  text: string;
  label: string;
  item: T;
}

export interface SatCatalogOptionsConfig<T extends SatCatalogRecord = SatCatalogRecord> {
  activeOn?: Date | string;
  separator?: string;
  filter?: (item: T) => boolean;
}
```
