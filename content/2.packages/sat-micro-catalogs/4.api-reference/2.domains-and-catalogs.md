## Convención de nombres

Cada tabla SQLite convertida a `snake_case` (por ejemplo `cfdi_40_usos_cfdi`) genera un módulo individual importable desde `@nodecfdi/sat-micro-catalogs/catalogs/<slug>` con tres símbolos:

| Símbolo | Ejemplo (`cfdi_40_usos_cfdi`) | Tipo |
| --- | --- | --- |
| Instancia de catálogo | `cfdi40UsosCfdi` | `SatCatalog<Cfdi40UsosCfdiItem>` |
| Arreglo de datos crudos | `cfdi40UsosCfdiData` | `readonly Cfdi40UsosCfdiItem[]` |
| Interfaz de fila | `Cfdi40UsosCfdiItem` | `interface` generada con las columnas exactas |

```ts [app/types-example.ts]
import type { Cfdi40UsosCfdiItem } from '@nodecfdi/sat-micro-catalogs/cfdi-40';
import { cfdi40UsosCfdi } from '@nodecfdi/sat-micro-catalogs/cfdi-40';

const uso: Cfdi40UsosCfdiItem | undefined = cfdi40UsosCfdi.get('G01');
```

::note
En los catálogos que no son clave-valor (como `cfdi_40_reglas_tasa_cuota`), el símbolo principal exporta directamente `readonly Item[]`. Revisa [Catálogos especiales](/packages/sat-micro-catalogs/api-reference/special-catalogs) para ver los detalles.
::
