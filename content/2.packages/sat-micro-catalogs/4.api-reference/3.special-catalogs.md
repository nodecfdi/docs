Aunque la mayoría de los catálogos del SAT tienen columnas `id` y `texto`, 11 tablas tienen un esquema diferente. El generador detecta automáticamente estas variaciones y configura cada catálogo correctamente.

## 1. Catálogos de estados (`estado` + `texto`)

Aplica a: `cfdi40Estados`, `nominaEstados`, `cce20Estados` y `cceEstados`.

Se configuran automáticamente con `{ keyField: 'estado', textField: 'texto' }`, por lo que puedes consultar directamente por clave de estado y filtrar por país:

```ts [app/estados.ts]
import { cfdi40Estados } from '@nodecfdi/sat-micro-catalogs/cfdi-40';

cfdi40Estados.text('AGU'); // "Aguascalientes"
cfdi40Estados.label('AGU'); // "AGU - Aguascalientes"

// Opciones para <select> solo de México
const estadosMexico = cfdi40Estados.options({
  activeOn: new Date(),
  filter: (item) => item.pais === 'MEX',
});
```

## 2. Hidrocarburos y Petrolíferos (`id` + `descripcion`)

Aplica a: `hyp10ClavesHyp`, `hyp10SubproductosHyp` y `hyp10TiposPermisos`.

Usan `descripcion` en lugar de `texto` y se configuran con `{ keyField: 'id', textField: 'descripcion' }`:

```ts [app/hyp.ts]
import { hyp10ClavesHyp } from '@nodecfdi/sat-micro-catalogs/hyp-10';

const primero = hyp10ClavesHyp.all()[0];
hyp10ClavesHyp.text(primero.id); // Devuelve primero.descripcion
```

## 3. Tipos de factores (solo `id`)

Aplica a: `cfdi40TiposFactores` y `cfdiTiposFactores`.

Estas tablas no tienen columna de descripción; se configuran con `{ keyField: 'id', textField: 'id' }`. Cuando `keyField === textField`, `.label()` y `.options()` no duplican el valor con separador:

```ts [app/factores.ts]
import { cfdi40TiposFactores } from '@nodecfdi/sat-micro-catalogs/cfdi-40';

cfdi40TiposFactores.text('Tasa'); // "Tasa"
cfdi40TiposFactores.label('Tasa'); // "Tasa" (no "Tasa - Tasa")
```

## 4. Reglas de tasa o cuota (tabla de reglas)

Aplica a: `cfdi40ReglasTasaCuota` y `cfdiReglasTasaCuota`.

No tienen una clave única porque representan combinaciones válidas de impuesto, factor, rango/fijo y traslado/retención. Se exportan directamente como `readonly Item[]`:

```ts [app/tasa-cuota.ts]
import { cfdi40ReglasTasaCuota } from '@nodecfdi/sat-micro-catalogs/cfdi-40';

const reglasIvaTraslado = cfdi40ReglasTasaCuota.filter(
  (regla) => regla.impuesto === 'IVA' && regla.traslado === 1,
);
```
