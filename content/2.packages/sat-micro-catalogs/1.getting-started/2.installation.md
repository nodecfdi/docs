`@nodecfdi/sat-micro-catalogs` no tiene dependencias en tiempo de ejecución ni requiere archivos de configuración.

## Instalar con tu gestor de paquetes

::code-group
```bash [pnpm]
pnpm add @nodecfdi/sat-micro-catalogs
```

```bash [npm]
npm install @nodecfdi/sat-micro-catalogs
```

```bash [yarn]
yarn add @nodecfdi/sat-micro-catalogs
```

```bash [bun]
bun add @nodecfdi/sat-micro-catalogs
```
::

## Verificación rápida

Importa un dominio y consulta una clave para confirmar que la instalación funciona correctamente:

```ts [index.ts]
import { cfdi40Monedas, cfdi40UsosCfdi } from '@nodecfdi/sat-micro-catalogs/cfdi-40';

console.log(cfdi40UsosCfdi.label('G01'));
// "G01 - Adquisición de mercancías."

console.log(cfdi40Monedas.text('MXN'));
// "Peso Mexicano"
```

## Uso sin instalación (navegador)

Si trabajas en una aplicación sin bundler (HTML plano, Laravel Blade, PHP, Rails, etc.), puedes cargar directamente los bundles IIFE desde un CDN. Consulta la sección de [Navegador (IIFE)](/packages/sat-micro-catalogs/browser/iife-bundles) para ver todos los bundles y variables globales disponibles.
